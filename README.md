## Цель
Настроить веб-сервер Nginx, HTTPS, автоматическое развёртывание сайта и аудит безопасности.

## Окружение
- Хост: macOS
- Виртуальная машина: Ubuntu 26.04
- Веб-сервер: Nginx
- Передача файлов: rsync через SSH
- Контроль версий: Git

## Структура проекта
- `site/` — файлы сайта
- `scripts/deploy.sh` — автоматическое развёртывание
- `scripts/audit.sh` — аудит безопасности

## Развёртывание
Пробный запуск:

    ./scripts/deploy.sh --dry-run

Настоящий запуск:

    ./scripts/deploy.sh

Скрипт проверяет наличие index.html, чистоту Git и доступность HTTPS.

## Аудит
Запуск:

    ./scripts/audit.sh

Проверяются Nginx, HTTP, HTTPS, права сертификата, небезопасные файлы и UFW.
